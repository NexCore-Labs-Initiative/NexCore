# Code of Conduct

NexCore Labs is committed to a respectful, inclusive student-community environment. Be considerate, assume good intent, give actionable feedback, and never harass, threaten, discriminate against, or expose another person's private information.

Project maintainers may edit or remove contributions and restrict participation when behavior harms the community or the project. Report conduct concerns privately to the repository maintainers. Reports will be handled as confidentially as practical.

This standard applies in repository discussions, pull requests, community spaces, and public representation of the project.
